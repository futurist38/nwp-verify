# 초기 운량–DSR 관계를 M4 운량예측에 적용하는 실험

사용자 제안(2026-10-22): 초기장의 위성 운량(CA)과 위성센터 DSR을 짝지어 관계를
기억하고, 미래 M4 운량값에 적용해 일사량을 예측한다. **운영 배포와 별도인 소급 실험**이다.
COT, 새 DL 학습, NWP 일사량 결합은 이번 단계에 포함하지 않는다.

## 방법

- UTC 2026-10-19/20/21 01:00(한국시간 10:00) 발령, +30/60/120/180분.
- 실제 GK2A CLA와 SWRAD의 동시각 수치장을 900→512 격자로 면적평균한다.
- 초기장 한 시각에서 CA 5%p 구간별 평균 DSR 또는 평균 DSR/청천참조량을 구한다.
  각 구간 최소 64개 유효 화소. 구간별 10~90백분위는 관계의 모호함을 나타내는 산포다.
- 관계표를 보정 전 M4 예측 CA에 적용한다. PMM/PNG 밝기와 별도 이류는 사용하지 않는다.
  분포 이동은 M4 예측장을 통해 반영되며, 개별 구름의 물리적 속성 추적은 아니다.
- 직접 매칭 `DSR=f(CA_M4)`와 태양고도 보정 `DSR=g(CA_M4)*G_clear(valid)`를 함께 시험한다.
- 태양고도 보정은 NOAA 근사 태양위치+Haurwitz 참조 일사량을 사용한다.
  에어로졸/수증기를 정밀하게 반영한 청천 진실값은 아니다. 비율 >1을 임의로 자르지 않는다.
- 표본이 없는 운량 구간, 결측값은 미산출로 유지한다. 초기/검증 시각 태양고도 ≥15°.

## 검증

미래 DSR은 관계표를 동결하고 예측한 뒤에만 읽는다. 초기장 적합도를 미래 예측 성능으로
취급하지 않는다. 고정 DSR 유지 및 청천비율 유지 예측과 **완전히 같은 유효 화소**에서
MAE/RMSE/bias를 비교하고 커버리지를 함께 보고한다. 관계 학습 영역은 한반도 주변
(123~133E,31~41N; 해상 포함), 평가 영역은 남한 및 한반도 육지(Natural Earth 110m)다.
국가 경계 자료의 해상도 때문에 작은 섬 일부는 평가에 포함되지 않을 수 있다.

`diagnostic_actual_ca.csv`는 미래의 실제 CA를 대입한 진단이다. 예보가 아니며, 관계표의
시간 전이 문제와 M4 운량 오차를 구분하기 위한 보조 비교다. 이 경우도 별도의 공통 화소로 비교한다.

검증 대상 DSR도 위성 추정 산출물이므로 **독립 지상 일사 검증이 아니다**.
초기 3일·각 하루 1개 발령은 작동/가능성 확인 수준이며 계절별 우열 판정 근거가 될 수 없다.
공통 유효 화소만의 점수와 전체 생산 범위는 다르므로 scores.csv의 coverage를 반드시 확인한다.
기존 운량예측 모델 가중치의 SHA256 및 코드 SHA를 provenance.json에 남긴다.

## 실행·보관

```bash
python -m unittest discover -s tests -p test_solar_ca_mapping.py -v
python solar_dsr_experiment.py --issues 202610190100 202610200100 202610210100
```

기존 KMA_AUTH_KEY 및 Release의 gk2a_v5 모델을 사용한다. 원자료는 Actions 임시 디스크에만
받으며, 저장소에는 작은 표·관계표·그림·실행시간만 보관한다. 실험 브랜치 전용 워크플로는
위 실험 코드 변경 시 실행되며 정기 스케줄/운영 화면 발행은 없다.

참고식: [NOAA 태양위치](https://gml.noaa.gov/grad/solcalc/solareqns.PDF),
[Haurwitz 청천 일사량](https://pvlib-python.readthedocs.io/en/stable/reference/generated/pvlib.clearsky.haurwitz.html).
